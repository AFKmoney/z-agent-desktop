Z.AGENT

Autonomous Desktop Agent

Transform your computer into a remotely-controllable system. Send tasks in natural language via Telegram, the agent plans, executes, and notifies you — using GLM-4.6 / 4V / 4.5 / 5.x for reasoning, vision, and execution.

Advanced capabilities

✨

ReAct Loop

Reason → Act → Observe → Critique. The agent adapts to failures and replans mid-task, instead of executing a fixed plan blindly.

🐍

Code Interpreter

Sandboxed Python execution for data analysis, file parsing, math, and custom automation. Whitelist-based imports, resource limits.

🔍

Web Search

Real-time web search and page reading via z-ai-web-dev-sdk. Deep research mode reads top results and synthesizes findings.

🤖

Multi-Agent Orchestrator

Spawns specialized sub-agents (researcher, coder, file_organizer, communicator...) running in parallel for complex tasks.

🧠

Skill Library

The agent learns from its successes. Reusable action sequences are saved as skills and reused when similar goals appear.

🎙️

Voice Control

Send voice messages to the Telegram bot — Whisper transcribes them and the agent processes them as text. TTS for replies.

💬

Conversation Context

Long-term multi-task memory. Follow-up requests like "do the same for Documents" work because the agent remembers past turns.

🔌

Plugin Marketplace

Install third-party plugins from local paths, zips, or git URLs. Each plugin extends the agent with new actions.

🌐

MCP Integration

Connect to any Model Context Protocol server — filesystem, GitHub, Postgres, Slack, Puppeteer — and use their tools natively.

📹

Vision Streaming

Continuous screen monitoring with change detection. Watchers trigger notifications when specific UI elements appear.

🪟

100% Windows Control

PowerShell, registry, services, COM (Outlook/Excel/Word), window management, Wi-Fi, volume, brightness, wallpaper, event log.

⚡

Native Tool Calling

Uses GLM's native function-calling API for reliable multi-round tool invocation — no more JSON parsing failures.

Quick start

# 1. Clone git clone https://github.com/AFKmoney/z-agent-desktop.git cd z-agent-desktop # 2. Install python -m venv venv source venv/bin/activate # Windows: venv\Scripts\activate pip install -r requirements.txt playwright install chromium # 3. Configure cp .env.example .env # Edit .env with your ZAI_API_KEY, TELEGRAM_BOT_TOKEN, etc. # 4. Run python main.py --check # Verify config python main.py # Start (Telegram + Web API + Notifier)

Get your API keys: z.ai API key · Telegram bot token · Gmail app password
